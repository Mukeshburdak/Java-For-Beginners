# Java-For-Beginners

This repository represents my Java learning journey and skill development. It contains Core Java programs covering fundamental and intermediate concepts, shared openly to help others learn, practice, and grow through clear, well-structured, and practical examples.

---
🚀 Topics Covered
-
> Java Basics & Syntax

> Object-Oriented Programming (OOP)

> Exception Handling

> Collections Framework

---
🛠 Requirements
-
Java JDK 8 or above

Any IDE (VS Code, IntelliJ IDEA, Eclipse)

---
▶ How to Run
-
Clone the repository

git clone https://github.com/Mukeshburdak/Java-For-Beginners.git

Open the project in your IDE

Compile and run any .java file
